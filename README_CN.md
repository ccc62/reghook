# RegHook v2（ARM64）

这是一个用于自有测试程序的实验性 Android ARM64 硬件执行断点/寄存器写回原型。

## 输入方式

- PID：目标进程 PID
- 断点地址：代码指令地址，十六进制，例如 `70AA42C95C` 或 `0x70AA42C95C`
- 寄存器：`X8`、`x8` 或 `8` 均可（X0-X30）
- 写入值：十六进制，例如 `1F4` 或 `0x1F4`

输入会尝试移除常见的零宽和双向文本控制字符，并在启用前打印完整配置供核对。

## 构建

GitHub Actions 的 `Build Android ARM64` workflow 会使用 Android NDK 构建 ARM64 可执行文件，并上传 artifact。

## 重要限制

- 本版用 `ptrace` 跟踪目标进程线程，并使用 Linux `perf_event_open` 请求硬件执行断点；目标线程在初始化和命中处理时会短暂停止。
- Android 内核、SELinux、perf 权限、内核对 `TRAP_PERF` 的报告方式及硬件断点资源均可能影响运行。此代码未在真实设备上验证，编译成功不等于运行成功。
- 只枚举启动时已存在的线程；后续新建线程不会自动加入。
- 不支持修改 SP/PC/PSTATE；仅支持 X0-X30。将 64 位值写入 Xn 时，Wn 显示其低 32 位。
- 请先在自己编写的测试程序中验证，避免在重要游戏进程中使用。发生异常时用 Ctrl+C 退出。
